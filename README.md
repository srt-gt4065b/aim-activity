# AIM Activity Log · AI경영학과 격주 활동 입력

우송대학교 AI경영학과 교수진이 격주 업무보고용 활동을 입력하는 웹사이트입니다.

- 로그인 없이 이름을 선택해 입력합니다 (선택한 이름은 기기에 기억됩니다).
- 한국어 / English / 中文 전환, 휴대폰·데스크톱 화면 모두 지원합니다.
- 데이터는 Firebase Realtime Database에 저장되고, 다른 사람이 입력하면 화면에 바로 반영됩니다.
- 학과에서 공유한 전용 링크(`…/#k=접근키`)로 들어와야 입력·조회할 수 있습니다. 접근 키는 이 저장소에 들어 있지 않습니다.
- 파일은 `index.html` 하나입니다. 수정 후 이 저장소에 올리면 GitHub Pages에 반영됩니다.
- 주소 끝에 `?demo=1`을 붙이면 예시 데이터로 화면을 둘러볼 수 있습니다 (저장되지 않음).

## 보고 기간

격주 기간은 2026-09-21(월)을 기준으로 14일씩 나뉩니다 (`index.html`의 `ANCHOR`).
